# Heal Hospital — Appointment Booking UX Design

## Overview
Heal Hospital is a university Human–Computer Interaction (HCI) group project focused on designing a mobile app for hospital appointment booking.

The project explores how patients can book, reschedule, and cancel appointments, view appointment details, and receive reminders through a clear interface. It also considers the needs of hospital staff and patients with different levels of experience using technology.

## Project Scope
This repository presents the project's research, design, and usability evaluation.

The application is a prototype and is not connected to a hospital database or a live appointment management system.

## Project Contents
- User research through interviews and questionnaires.
- User personas and task analysis.
- Interface designs and an interactive Figma prototype.
- Usability testing with five participants.
- Evaluation findings and proposed design improvements.
